
## 1. 正常读字符串（无空格）
```cpp
string s;
cin >> s;
cout << s;
```
✅ 读：连续字符串（遇到空格/回车停止）  
✅ 写：输出字符串  
✅ 比赛最常用

## 2. 读**带空格**的一行字符串
```cpp
string s;
getline(cin, s);
cout << s;
```
✅ 读一整行，包括空格  
⚠ 注意：前面如果用了 cin >> ，要先吸收换行

## 3. 循环读到**文件结束 EOF**（ACM 最最最常用！）
```cpp
string s;
while (cin >> s) {
    // 处理 s
}
//or
for(int i=0;s[i];i++){
    // 处理 s
}
```
👉 直接替代你原来的  
`while(scanf("%c",&x)!=EOF)`  
👉 读到没有输入就停止  
👉 **ACM 90% 读字符串都用这个**

## 4. 输出字符串
```cpp
cout << s << endl;    // 输出并换行
cout << s;            // 输出不换行
```

    }

    }
