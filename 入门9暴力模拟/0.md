递归思考总结
# 二、递归标准生成写法（通用模板，套任何题都能用）
递归不是凭空写的，有固定四步构造流程，拿你这道烤鸡手把手演示怎么一步步写出代码：
## 步骤1：定义递归函数的含义（最重要）
先说清楚：这个函数是干嘛的，参数代表什么。
本题需求：
现在已经选了前 `a` 种配料，总重量是 `total`，继续填第 a、a+1…9 种配料，枚举所有可能。
所以函数定义：
`void dfs(int total, int a)`
- total：前a个配料总和
- a：当前要填第 a 号配料（0~9）

## 步骤2：写递归出口（终止条件，对应数学归纳基例）
什么时候不用再拆分？所有配料填完，也就是 `a == 10`。
到边界只做判断：总和等于n就是合法方案，存起来。
```cpp
if(a == 10)
{
    if(total == n) 存方案、计数+1;
    return; // 必须返回，停止往下递归
}
```

## 步骤3：剪枝优化（可选，提升速度）
如果现在总和已经 ≥n，后面每种至少加1，总和只会更大，不可能合法，直接不枚举：
```cpp
if(total >= n) return;
```

## 步骤4：枚举所有当前位置的可能值，递归下一层（递推步骤）
当前配料只能取1/2/3，循环每种取值：
1. 记录当前选的值到临时数组
2. 新总和 = total + 当前重量
3. 下一层处理 a+1 号配料，调用自身递归
```cpp
for(int i = 1; i <= 3; i++)
{
    m2[a] = i;
    dfs(total + i, a + 1);
}
```

## 步骤5：组装完整递归函数 + 主函数调用
初始状态：还没填任何配料（a=0）、总和0，调用 `dfs(0,0)`。

# 三、通用万能递归模板（以后所有枚举/搜索题直接套）
## 模板框架
```cpp
// 1. 定义函数：描述当前处理到哪一步、已积累信息
void dfs(状态参数1, 状态参数2, ...)
{
    // 2. 递归出口：问题全部处理完毕
    if(到达终点条件)
    {
        判断是否符合要求，记录答案;
        return;
    }

    // 可选：剪枝，不可能有解直接返回
    if(无法满足条件) return;

    // 3. 枚举当前位置所有可选取值
    for(每个可能选择)
    {
        记录当前选择到临时数组/变量;
        dfs(更新后的状态参数); // 递归处理下一步
    }
}

int main()
{
    读入数据;
    dfs(初始状态参数); // 启动递归
    输出统计的答案;
}
```

## 套用在烤鸡上对应关系一目了然
1. 函数：`dfs(total,a)` 记录当前总和、当前配料编号
2. 出口：`a==10` 10种配料全部填完
3. 剪枝：`total>=n` 直接放弃
4. 枚举：i=1,2,3 三种重量，更新状态 `total+i，a+1`
5. 初始调用：一无所有 `dfs(0,0)`

# 补充小总结
1. 思想关联：递归 ≈ 反向数学归纳，都是「边界+递推」；归纳从少推多，递归从多拆少。
2. 递归生成流程固定：**定函数含义 → 写终止出口 → 加剪枝 → 循环枚举递归下一层 → 初始调用**，按这个顺序写永远不会卡壳。
3. 你这道属于**暴力枚举型递归**（深度优先搜索DFS），是最简单的递归类型，所有排列、组合、多变量枚举题都能用这套模板。
