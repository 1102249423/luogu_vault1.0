2新东西
a[1..5] = {1,2,2,3,3}
auto p = unique(a+1,a+n+1); p 指向 a[4]
p - (a+1) 等价 &a[4] - &a[1] = 3
现在 n 代表：数组只剩 1,2,3 三个不重复数。

```c++
sort(a + 1,a + n + 1);//排序
	n = unique(a + 1,a + n + 1) - (a + 1);//unique 只对有序数组生效，它不会真的删除重复元素，只是把相邻重复元素挪到数组尾部，返回一个迭代器 / 指针，指向去重后最后一个有效元素的下一位。这样子一旦减掉最开始就是不重复的元素
```
